# Кредитный скоринг

Классификация одобрения кредита на Kaggle Loan Approval: EDA, признаки, сравнение моделей, Optuna и интерпретация.

Автор: Ерофеев Илья. Учебный проект.

## Запуск

1. Установите Python и зависимости: `pip install -r requirements.txt`.
2. Скачайте [датасет](https://www.kaggle.com/datasets/taweilo/loan-approval-classification-data) и разместите файл `loan_data.csv` рядом с ноутбуком.
3. Откройте `analysis.ipynb` в Jupyter и выполните ячейки по порядку.

Сохранённые результаты находятся в ноутбуке. Метрики и выводы следует оценивать вместе с описанным в нём способом валидации.
